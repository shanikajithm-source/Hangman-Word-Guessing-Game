# Hangman Word Guessing Game

## Project Overview
Hangman is a beginner-friendly Python word-guessing game. The player attempts to discover a randomly selected hidden word by guessing one letter at a time.

## Features
- Random word selection
- Hidden word display
- ASCII Hangman drawing
- Six incorrect guesses allowed
- Displays previously guessed letters
- Prevents duplicate guesses from reducing attempts
- Input validation
- Win and lose messages

## Technologies Used
- Python 3
- `random` module

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   `python hangman.py`

## Learning Outcomes
This project demonstrates Python variables, lists, loops, conditional statements, string operations, user input, and the use of built-in modules.
